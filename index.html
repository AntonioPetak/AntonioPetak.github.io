Dynamic Multi-Tenant API ETL Engine & Data Pipeline

A highly scalable, modular ETL pipeline developed entirely in Power Query (M Language) to automate data ingestion from a REST API across multiple dynamic targets. Built around DRY (Don't Repeat Yourself) architecture, the engine utilizes secure environment parameters (pApiUser, pApiPassword, pApiBaseUrl) and a flexible configuration dataset (ConfigDatabases) to drive pagination and data extraction. A custom M function (fnGetApiView) handles dynamic HTTP requests, pagination loops, response parsing, and error handling. The function iteratively executes for each configured country/database, dynamically combining disparate payload views into unified, reporting-ready data tables (Views 1–5).
